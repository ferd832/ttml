# 🚀 Инструкция по установке и запуску TTML Studio

## 📋 Системные требования

- **Node.js** версии 18.0 или выше
- **npm** версии 8.0 или выше (обычно идёт вместе с Node.js)
- **Git** (для загрузки проекта)

### Проверка установленных версий

Откройте терминал (командную строку) и выполните:

```bash
node --version    # Должна быть v18.0.0 или выше
npm --version     # Должна быть 8.0.0 или выше
git --version     # Должна показать версию Git
```

Если Node.js не установлен, скачайте его с [официального сайта](https://nodejs.org/) (рекомендуется LTS версия).

## 📥 Шаг 1: Загрузка проекта

### Вариант А: Клонирование с GitHub (рекомендуется)

```bash
# Перейдите в папку, где хотите разместить проект
cd ~/Projects  # или любая другая папка

# Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/ttml-studio.git

# Перейдите в папку проекта
cd ttml-studio
```

⚠️ **Важно:** Замените `YOUR_USERNAME` на ваш username GitHub!

### Вариант Б: Ручная загрузка файлов

Если у вас нет GitHub или вы хотите создать проект с нуля:

1. Создайте новую папку для проекта:
```bash
mkdir ttml-studio
cd ttml-studio
```

2. Создайте все файлы из списка ниже (см. раздел "📁 Структура проекта")

---

## 🔧 Шаг 2: Установка зависимостей

В папке проекта выполните:

```bash
npm install
```

Эта команда:
- Скачает все необходимые библиотеки (React, Vite, Tailwind CSS и др.)
- Создаст папку `node_modules/` с зависимостями
- Займёт 1-3 минуты в зависимости от скорости интернета

✅ После успешной установки вы увидите сообщение вроде:
```
added 245 packages in 45s
```

---

## 🎯 Шаг 3: Запуск проекта

### Режим разработки (с горячей перезагрузкой)

```bash
npm run dev
```

Вы увидите:
```
  VITE v6.3.5  ready in 500 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

Откройте браузер и перейдите по адресу: **http://localhost:3000**

🎉 **Готово!** TTML Studio запущена!

### Режим продакшена (сборка для деплоя)

```bash
npm run build
```

Эта команда:
- Создаст оптимизированную версию приложения
- Сохранит файлы в папку `dist/`
- Эти файлы можно загрузить на любой хостинг

Для локального просмотра собранной версии:

```bash
npm run preview
```

## 🎮 Использование приложения

### 1. Загрузка аудио
- Нажмите на область "Аудио файл"
- Выберите файл (WAV, MP3, OGG)
- Дождитесь загрузки и анализа волны

### 2. Ввод текста
**Вариант А: Построчный ввод**
- Нажмите "+ Добавить строку"
- Введите текст в поле

**Вариант Б: Массовый импорт**
- Нажмите "📋 Вставить текст"
- Вставьте весь текст (каждая строка = новая строка)
- Нажмите "Импортировать"

### 3. Синхронизация
1. Перейдите в режим "🎵 Синхронизация"
2. Запустите воспроизведение аудио
3. Когда начинается строка, нажмите **Space** или кнопку "Синхронизировать"
4. Переходите к следующей строке клавишами **↑↓** или кликом

### 4. Экспорт
1. Нажмите "Скачать"
2. Выберите формат:
   - **TTML** - для Apple Music / Musixmatch
   - **LRC** - универсальный формат для плееров
3. Файл скачается автоматически

## 🐛 Решение проблем

### Проблема: `npm: command not found`
**Решение:** Установите Node.js с [nodejs.org](https://nodejs.org/)

### Проблема: Порт 3000 уже занят
**Решение:** 
```bash
# Остановите другой процесс или измените порт в vite.config.js:
server: {
  port: 3001  # или любой другой свободный порт
}
```

### Проблема: Белый экран в браузере
**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте на наличие ошибок
3. Перезапустите `npm run dev`
4. Очистите кэш браузера (Ctrl+Shift+R)

### Проблема: Ошибки при `npm install`
**Решение:**
```bash
# Удалите старые файлы и переустановите
rm -rf node_modules package-lock.json
npm install
```

### Проблема: Аудио не воспроизводится
**Решение:**
- Проверьте формат файла (должен быть WAV, MP3 или OGG)
- Убедитесь, что браузер поддерживает Web Audio API
- Попробуйте другой браузер (Chrome/Firefox/Safari)

## 📦 Деплой на хостинг

### Vercel (рекомендуется)

1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Подключите GitHub репозиторий
3. Vercel автоматически определит Vite проект
4. Нажмите "Deploy"

### Netlify

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку `dist/` в интерфейс
3. Или подключите GitHub для автоматического деплоя

### GitHub Pages

```bash
# Установите gh-pages
npm install -D gh-pages

# Добавьте в package.json:
"scripts": {
  "deploy": "npm run build && gh-pages -d dist"
}

# Запустите деплой
npm run deploy
```
