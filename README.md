# 🪐 TTML Studio - PLANET MUSIC

Космическая студия для создания синхронизированных текстов песен в форматах TTML, LRC и SRT.

## 🔐 Авторизация

Приложение защищено авторизацией через Supabase.

### Настройка Supabase

1. **Создайте проект на [Supabase](https://supabase.com)**
   - Зарегистрируйтесь и создайте новый проект
   - Дождитесь активации проекта (обычно 1-2 минуты)

2. **Настройте Authentication**
   - Перейдите в раздел **Authentication** → **Providers**
   - Убедитесь что **Email** провайдер включён
   - Опционально: отключите "Confirm email" для упрощения входа

3. **Получите ключи API**
   - Перейдите в **Settings** → **API**
   - Скопируйте **Project URL** и **anon/public key**
   - Добавьте их в файл `.env`:
     ```env
     VITE_SUPABASE_URL=your_project_url
     VITE_SUPABASE_ANON_KEY=your_anon_key
     ```

4. **Создайте пользователя**
   - Перейдите в **Authentication** → **Users**
   - Нажмите **Add user** → **Create new user**
   - Введите email и пароль
   - Сохраните пользователя

### Вход в приложение

Используйте созданный email и пароль для входа в студию.

### Настройка системы приглашений

Для регистрации новых пользователей нужны коды приглашения:

1. **Выполните SQL в Supabase:**
   - Откройте **SQL Editor** в Supabase Dashboard
   - Скопируйте содержимое файла `SUPABASE_SETUP.sql`
   - Выполните SQL для создания таблицы `invite_codes`

2. **Создайте коды приглашения:**
   ```sql
   INSERT INTO invite_codes (code) VALUES 
     ('PLANET2026'),
     ('MUSIC2026'),
     ('STUDIO2026');
   ```

3. **Раздайте коды:**
   - Отправьте коды приглашения пользователям
   - При регистрации пользователь вводит код
   - Код помечается как использованный

### Регистрация нового пользователя

1. На экране входа нажмите "Нет аккаунта? Зарегистрироваться"
2. Введите код приглашения (например: PLANET2026)
3. Введите email и пароль
4. Нажмите "Зарегистрироваться 🚀"

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте ваши ключи Supabase:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

**Важно:** Никогда не коммитьте `.env` файл в git! Он уже добавлен в `.gitignore`.

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 4. Сборка для продакшена

```bash
npm run build
```

## ✨ Возможности

### 🎵 Основные функции
- **Загрузка аудио** - поддержка WAV, MP3, OGG форматов
- **Визуализация волны** - реальная форма волны из аудиофайла
- **Редактор текста** - добавление и редактирование строк
- **Синхронизация** - привязка текста к аудио с обратным отсчётом
- **Предпросмотр** - просмотр в стиле Apple Music/Spotify
- **Экспорт** - сохранение в форматах TTML, LRC и SRT
- **История действий** - undo/redo для всех изменений

### ⏱ Точная настройка времени
- **Тонкая adjustment** - сдвиг таймкода на ±0.1 секунду
- **Быстрые кнопки** - ±0.1s, ±0.5s, ±1s для каждой строки
- **Ручной ввод** - точное время в формате MM:SS.mmm
- **Глобальный сдвиг** - сдвиг всех таймкодов одновременно
- **Прослушивание строки** - воспроизведение конкретной строки

### 🔍 Поиск и навигация
- **Поиск по тексту** - быстрый поиск строк
- **Автоматическая прокрутка** - к текущей строке в режиме синхронизации
- **Горячие клавиши** - Space, ↑↓ для навигации

### 💾 Дополнительные функции
- **Автосохранение** - прогресс сохраняется в localStorage
- **Восстановление черновика** - предложение восстановить при загрузке
- **Drag & Drop** - перетаскивание строк для изменения порядка
- **Импорт файлов** - загрузка .lrc и .ttml файлов
- **Мультиязычность** - интерфейс на 7 языках

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` | Синхронизировать текущую строку |
| `↑` / `↓` | Навигация между строками |
| `Ctrl+Z` | Отменить действие |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Повторить действие |

## 📄 Форматы экспорта

### TTML (Apple Music)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<tt xmlns="http://www.w3.org/ns/ttml" 
    xmlns:itunes="http://itunes.apple.com/lyric-ttml-extensions">
  <body>
    <div>
      <p begin="00:00:14.595" end="00:00:18.399">Текст строки</p>
    </div>
  </body>
</tt>
```

### LRC (универсальный)
```
[00:14.595] Текст строки
[00:18.399] Следующая строка
```

### SRT (субтитры)
```
1
00:00:14,595 --> 00:00:18,399
Текст строки
```
